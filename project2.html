PROJECT 02

PERKASA

Satu Aksi Berarti, Warisan Lestari untuk Bumi

Deskripsi Project

Proyek PERKASA (Persaudaraan Kanisius Sayang Alam) adalah sebuah inisiatif pengembangan situs web yang bertujuan untuk mendigitalisasi gerakan pelestarian lingkungan yang dilakukan oleh komunitas siswa Kanisius. Latar belakang pembuatan proyek ini didorong oleh masalah degradasi lingkungan dan penumpukan sampah di area publik. Meskipun komunitas ini secara konsisten mendedikasikan waktu untuk melakukan aksi bersih-bersih setiap minggu, jangkauan pengaruh mereka sebelumnya masih terbatas oleh sistem komunikasi dan dokumentasi yang belum terintegrasi secara digital.

Teknologi yang Digunakan

  • HTML5 — Dokumen Induk HTML ➔ Halaman Landing Page (Menampilkan Visi Misi & Nilai Komunitas) ➔ Navigasi Utama ➔ Halaman Activities (Jadwal & Kartu Kegiatan) ➔ Halaman Membership (Formulir Pendaftaran Relawan & Kontak).
  • CSS3 — Pendekatan Desain Responsif Lintas Perangkat ➔ Penerapan Kontras Warna Tinggi untuk Keterbacaan ➔ Sistem Kolom Rapi untuk Elemen Nilai Komunitas ➔ Lencana Status Indikator Visual (Warna Hijau & Abu-abu) ➔ Penataan Elemen Antarmuka Ramah Sentuhan (Touch-friendly).
  • JavaScript — Infrastruktur Lingkungan Vercel/Next.js ➔ Logika Filter Instan Kegiatan (All Events, Upcoming, Finished) ➔ Validasi Pengisian Data Formulir Pendaftaran ➔ Banner Edukasi Dinamis (Mengambang di Bawah Layar) ➔ Logika Pengalihan Pendaftaran Eksternal (Grup WhatsApp).

Fitur Utama

  • Sistem Manajemen Aktivitas dengan Filter Instan
  • Visualisasi Data Kuantitatif
  • Pusat Manajemen Keanggotaan Terpadu

Catatan Pengembangan

Tantangan terbesar dalam pengembangan proyek ini berpusat pada optimasi kebutuhan non-fungsional situs, terutama perihal kualitas performa dan kecepatan akses. Mengingat para relawan sering kali harus membuka jadwal atau berkoordinasi menggunakan perangkat ponsel pintar (smartphone) langsung dari area lapangan—di mana stabilitas koneksi internet seluler sering tidak menentu—tim pengembang dituntut untuk memastikan waktu pemuatan (loading time) berjalan secepat mungkin. Di samping itu, antarmuka juga harus dirancang secara khusus dengan kontras warna tinggi dan tombol ramah sentuh untuk menjamin kenyamanan operasional pada segala jenis ukuran layar gawai
